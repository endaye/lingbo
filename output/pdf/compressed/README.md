# LINGBO Catalog PDFs, Compressed Set

This directory contains a separate sharing-oriented copy of all 10 catalog PDFs. The original PDFs in `output/pdf/` are unchanged.

- Page size: A4 portrait
- Page count: 439 total
- Compression: 144 DPI JPEG page rasterization, quality 82
- Total size: approximately 290.21 MiB to 74.42 MiB
- Size reduction: approximately 74.36%
- Trade-off: this set is image-based, so text is not selectable or searchable

The per-file sizes, page counts, and SHA-256 checksums are recorded in [`compression-manifest.json`](./compression-manifest.json).
